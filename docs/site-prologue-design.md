# 网站像素序章：《答案之前》

设计日期：2026-10-17。先确定叙事、分镜与播放规则，再实现。

## 主旨与文案

“AI 时代，更值得认识那些教会人类提问的人。”

开头从今天迅速抵达的答案切入，回望数、形、实验、证据与交流的形成；结尾邀请玩家亲自提问和研究。人物均来自游戏现有三十关。文化通过卷轴、手稿、书库、测绘与知识传递呈现，不添加游戏中未出现的历史名人，不编造人物引语。

| --- | --- | --- | --- |

这是概念蒙太奇，不是按人物生卒排序的历史年表。每幕有自己的环境、主体动作与配色；统一使用硬边像素、深夜蓝和航海金，以一颗移动微光保持连贯。人物沿用现有关卡的像素肖像。主要字幕与姓名使用清晰的 HTML 文字，避免把中文压进低分辨率画布。

## 播放与可访问性

- 首次进入当前标签页自动播放；跳过或看完后记录独立的 sessionStorage 标记。刷新不重复强制播放，不修改关卡进度。探索指南提供重播。
- 随时进入地图；支持上一幕、下一幕、暂停、九幕定位、空格暂停和 Escape 跳过；片头期间背景页面 inert，焦点留在片头，退出后恢复。
- 全片长度与真实地图加载分开显示，不能用固定动画进度伪装资源下载进度。地图在后台加载，失败时仍可退出片头使用索引。
- 中文旁白与原创轻量像素配乐默认关闭，点击声音后才启用。优先播放项目自带的中文旁白 MP3；加载失败时尝试浏览器中文朗读。离开片头停止语音、配乐、计时与动画。
- 页面切到后台暂停进度；返回后继续。减少动态效果模式默认暂停，允许逐幕阅读并使用静态构图。
- 手机保持人物、画面与字幕分区，控制区可触摸；横屏和小高度窗口允许片头内部滚动。

## 验收

检查开头、每幕中段、转场与结尾；核对人物是否来自关卡数据。覆盖暂停、跨幕、声音、跳过、完整播放、同标签页刷新、重播、手机、减少动态效果、键盘焦点、资源失败及现有关卡流程。

## 实现与检查结果

已接入 `index.html` 与中文 HTML 入口，两者内容保持一致。片头分为数据、Canvas 绘制、播放控制和样式四个独立文件，不依赖视频下载和图片生成服务。人物使用现有关卡的像素肖像；群像按英文姓名去重，同一人物跨学科出场不会重复计数。

`npm run check` 通过；147 项测试通过，其中新增测试覆盖片长、九幕人物来源、字幕切换边界、异常时间输入，以及全部旁白的文案、音频文件哈希与播放时长。

浏览器检查脚本：`output/playwright/site-prologue-check.js`。已验证连续九幕自动播放后退出、运动画面、暂停、后台暂停、九幕定位、跳过、存档隔离、会话刷新、指南重播、焦点循环、390px 手机、矮屏横向布局、减少动态效果、中文 HTML 入口、地图资源失败与 sessionStorage 不可用时仍可进入。

自带中文旁白位于 `assets/prologue/`，共 18 段、约 0.5 MB。由 Windows 的 Microsoft Huihui Desktop 语音离线合成，并经 FFmpeg 编码为 24 kHz 单声道 48 kbps MP3；每段校准到字幕时隙以内，避免句尾被下一幕截断。生产脚本为 `scripts/render-site-prologue-narration.ps1`，文案变更后可重新生成；完整文案与时长清单保存在 `assets/prologue/narration.json`。

浏览器已用实际 MP3 验证解码播放、暂停、跨幕切换与退出卸载；静音完整播放期间不请求任何旁白文件。另以受控的中文语音接口验证 MP3 失败时的浏览器朗读后备；配乐采用实际 Web Audio 上下文验证退出后关闭。默认不开声音，不强行自动播放音频。

另外走查原有物理十关入口与世界地图三岛进出、旧存档和恢复色彩流程，均通过，无页面异常。相关地图检查脚本在隔离测试会话中预置片头已看标记，片头自身的首次播放另行测试。

分幕图：`output/playwright/opening-scene-01.png` 至 `opening-scene-09.png`；手机图包括 `opening-mobile-observe.png`、`opening-mobile-light.png`、`opening-mobile-legacy.png`。

## 画面放大与比例修正

按用户反馈增加动画区高度和主体尺寸。桌面动画区高度至少 380px，并随视口增加；矮屏收紧标题和操作栏，手机保留独立布局。画布逻辑宽度按实际显示宽高比计算，移除导致超宽画面被横向拉伸的 1400px 上限。主体镜头采用统一的等比缩放，桌面放大至 1.25 倍，窄屏保留 640 个场景单位的观察范围。

`output/playwright/site-prologue-size-check.js` 验证 1762×900、1920×1080、1762×768、1440×960、1280×720、390×900 和 844×390 七种窗口：显示像素宽高比接近 1，地球不被拉扁；桌面操作按钮留在视口内，无横向溢出。另检查全部九幕和最终进入地图，无页面异常。更新后的截图以 `opening-larger-` 为前缀。
