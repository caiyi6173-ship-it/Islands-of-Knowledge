# 数学岛：从套用模板到演算工坊

本轮保留十位人物、两幕操作与最后的解释、版本 4 存档、三星与补给规则，重做了数学工作台和独立岛屿底图。

## 十关各自在玩什么

| 关卡         | 动手操作                                     | 画面与数学的联系                                                   |
| ------------ | -------------------------------------------- | ------------------------------------------------------------------ |
| 琴弦与数     | 选择弦长比、拨弦试听，再比较逼近分数         | 相同张力与线密度下，长度与基频成反比；平方残差与无理性证明分开呈现 |
| 未知量与方程 | 两端同时移除包裹、砝码，或选择等价的求解步骤 | 天平显示真实剩余项，不能移走不存在的物件                           |
| 坐标         | 直接拖动坐标点，或用滑块调节位置与直线斜率   | 网格、投影线、航标与坐标读数使用同一组数据                         |
| 函数         | 调节系数和偏置，对比输入输出；检验单值性     | 数值表即时改变，多个输入指向同一输出仍可构成函数                   |
| 二次函数     | 拖动顶点、调节开口，检查桥基与通行区         | 图形和净空由实际二次函数计算；不把几何尺寸当成承重结论             |
| 图形变换     | 拖动锚点平移，再顺时针旋转；检验缩放         | 先旋转再平移的图形与目标叠合，面积倍率为尺度因子的平方             |
| 几何         | 摇动四边框架、比较三角形；核对正方形面积     | 四边框架变形时边长保持不变，勾股关系须满足三角形与直角条件         |
| 向量         | 拖动船速箭头，观察渡船的实际航迹             | 船速与水流相加；抵达正对岸和最短渡河时间是两个目标                 |
| 变化率       | 缩小割线时间间隔，移动切线的观察时刻         | 割线、切线与读数都来自同一个示意函数                               |
| 数学建模     | 降低残差，再用留出日期检验预测               | 换幕后保留拟合参数；虚拟角度数据与真实轨道计算明确区分             |

## 操作与反馈

进入或重玩时播放开场，支持跳过与 Escape。桌面并排展示图形与操作台，手机纵向排列；所有人物形象有明确尺寸。调参使用局部 DOM 差异更新，保留 SVG、滑块和焦点。

自由操作、暂停、重播免费；正式记录才消耗时间和工具，失误扣信任。只改变一个条件时自动识别公平对照，首次优惠每幕一次。重复设置禁用正式提交。论证默认带入两幕最强的有效记录，玩家仍须选择解释及适用条件；错误结论可用现有记录免费修订。

「为什么成立」提供简短的定义、推理或模型边界。模拟和数值检验提供观察线索，不替代数学证明。
