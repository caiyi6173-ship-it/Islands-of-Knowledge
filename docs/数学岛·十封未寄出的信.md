# 数学岛 · 十封未寄出的信

按照物理岛“十封未寄出的信”与即时实验台模式，将数学学科节点（M01 至 M10）拓展为具备历史人物、科学矛盾、双幕实验操作、受控变量对照与证据论证的科学记忆关卡。玩家扮演学徒信使，与数学家共同在数与形、未知与方程、动态与变化中寻找线索，最终将发现写成寄往未来的信件。

---

## 游玩规则与架构

- **入口与视角**：在世界大地图选择“数学岛”或在顶栏切换到数学学科，即可进入数学岛的岛屿视角；地标、迷雾与行囊完全对齐物理岛规范。
- **一体化沙盒工作台**：每次进入关卡自动播放开场叙事与人物对话；跳过或播放完毕后进入一屏式工作台，左侧为像素舞台与实时可视化读数，右侧为实验控制台。
- **两幕递进实验**：
  - **初见（第 1 幕）**：在直观情境中动手探索核心数学规律，建立基本认识并留下首个证据。
  - **追问（第 2 幕）**：改变条件或提高精度，检验规律的普遍性与边界，留下第二个证据。
- **自由调参与正式提交**：
  - 滑块与选项调整为免费实时预览，不消耗资源，不计入正式失误。
  - 点击“提交正式实验”消耗时间与纸笔器材，检验是否达成当前幕目标；失败扣减信任，成功恢复信任并获得证据。
- **受控公平对照**：
  - 与同幕上一条正式实验相比，若且仅若只改变了一个输入条件，系统自动识别为公平对照。
  - 每幕首次公平对照享有资源优惠（耗时 1，免器材）；对照结果展示变量改动与读数差异。
- **论证与四种结局**：
  - 第 3 幕进入论证阶段，玩家选择解释立场、从实验记录中勾选 1～3 条证据，并划定结论的适用边界。
  - 四种结局：
    - **让证据发光（breakthrough，完整发现）**：跨两幕充足证据、正信任、合理的适用范围。
    - **一条新的航路（discovery，发现成立）**：证据成立但尚有局部边界待完善。
    - **问题仍在继续（provisional，保留结论）**：证据不足或选择保留问题以待后验。
    - **跑在证据前面的宣言（overreach，过度推断）**：将局部成立的结论无限制外推至所有情形。
- **三星评级与手记收录**：
  - ★ 发现成立：用证据支持结论，通关关卡。
  - ★★ 亲手验证：两幕均完成成功的正式实验。
  - ★★★ 对照研究：两幕均成功、完成公平对照、正式失误 ≤ 1 次、且未使用应急补给。
  - 通关后将人物手记与信件收录入探索手记与行囊中，并解锁地图局域复色。

## 关卡详案

### M01 琴弦数轴庭院 · 数与运算
- **人物**：毕达哥拉斯（PYTHAGORAS），古希腊
- **地标**：琴弦数轴庭院
- **危机对白**：“万物皆是和谐的整数比……可为什么这条对角线，把我们的尺子逼到了绝境？”
- **初见目标**：调节弦长比（2:3 或 3:4），使单弦共鸣箱发出纯五度/纯四度的和谐音程。
- **追问目标**：在网格直角三角形上测量单位边长的斜边 $\sqrt{2}$，用连分数逐步逼近，验证其无论如何无法被有限整数比穷尽。
- **信件**：后来的人：别因为手头的尺子量不出尽头，就假装那条对角线不存在。数系每一次痛苦的扩充，都在把人类的目光引向更开阔的真实。
- **公式**：$\sqrt{2} \notin \mathbb{Q}$，弦长比 $L_1 : L_2 = m : n$
- **模型边界**：单弦琴长理想化计算，忽略琴弦刚度与空气阻尼；逼近级数采用无量纲十进制与连分数阶数表示。

### M02 天平广场 · 未知量与方程
- **人物**：花拉子米（AL-KHWARIZMI），9 世纪阿拉伯
- **地标**：天平广场
- **危机对白**：“不要急着撕开包装。只要天平两边保持平衡，未知的东西自己会走出来。”
- **初见目标**：天平两侧有未知物包裹与固定砝码，双侧同时拿去相同重量（对消），直到一侧只留未知数。
- **追问目标**：面对倍数与复合负荷方程（如 $3x + 4 = 19$），先消去常数，再均分求出单个包裹真实重量。
- **信件**：后来的人：把不知道的东西也当作已知数那样写进等式里。只要守住对称与平衡，最隐秘的未知也会不攻自破。
- **公式**：$ax + b = c \implies x = (c - b) / a$（对消与还原）
- **模型边界**：理想杠杆无摩擦力矩，砝码与包裹质量均为标称正整数。

### M03 苍蝇测绘台 · 坐标
- **人物**：笛卡尔（RENÉ DESCARTES），17 世纪法国
- **地标**：苍蝇测绘台
- **危机对白**：“看天花板上的砖缝。任何一个漫无目的爬行的点，只要给它一对名字，就能被算出来。”
- **初见目标**：以房间角落为原点，在横竖网格上输入 $(x, y)$ 坐标定位迷雾中的目标航标。
- **追问目标**：观察移动点的连线，输入满足直线关系 $y = mx + c$ 的两对坐标，画出整条导航航线。
- **信件**：后来的人：给空间立下两道互相垂直的尺子。从那一刻起，几何的长袍被裁成了代数的战甲。
- **公式**：点 $P(x, y)$，两点间距离 $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$
- **模型边界**：笛卡尔右手直角坐标系，网格步长归一化为整数。

### M04 秩序机器花园 · 函数
- **人物**：欧拉（LEONHARD EULER），18 世纪瑞士
- **地标**：秩序机器花园
- **危机对白**：“每一枚投入齿轮的硬币，都必须有且仅有一张对应的车票。这就是函数的契约。”
- **初见目标**：设定加工机器的对应规则 $f(x) = kx + b$，让三组给定的原料与成品全部匹配。
- **追问目标**：串联非线性转化模块，分析复合对应 $g(f(x))$ 的输出表，杜绝“一进多出”的违约映射。
- **信件**：后来的人：世界不是一团纷乱的偶然。当你写下 $f(x)$ 时，因与果便有了庄严的契约。
- **公式**：$y = f(x)$，对定义域内任意 $x$，存在唯一的 $y$ 与之对应。
- **模型边界**：离散检验点与单值映射模型，不涉及多值函数分支割线。

### M05 抛物线石桥 · 二次函数
- **人物**：费马（PIERRE DE FERMAT），17 世纪法国
- **地标**：抛物线石桥
- **危机对白**：“半圆跨不过这么宽的山谷，而平木桥会被自重折断。唯有抛物线，能让两岸的重力温柔汇合。”
- **初见目标**：调节顶点高度 $k$ 与开口系数 $a$，让抛物线 $y = a(x - h)^2 + k$ 两端准确落在 12 米宽峡谷的基座上。
- **追问目标**：在中央桥下预留高 3 米、宽 6 米的货车安全净空，微调曲率同时满足跨距与通行限高。
- **信件**：后来的人：最高点从来不是凭空拔地而起的，它由左右完全对称的两道臂膀共同托向天空。
- **公式**：$y = a(x - h)^2 + k$（顶点式，对称轴 $x = h$）
- **模型边界**：理想悬垂与二次近似拱轴线，忽略材料弹性形变与局部应力集中。

### M06 变换镜廊 · 图形变换
- **人物**：克莱因（FELIX KLEIN），19 世纪德国
- **地标**：变换镜廊
- **危机对白**：“图形在镜子之间翻飞、旋转、拉伸。但在镜影翻滚的狂澜中，总有什么东西永恒静止。”
- **初见目标**：组合平移 $(\Delta x, \Delta y)$ 与旋转 $\theta$，将不规则钥匙图形送入机关槽，边长与内角完全守恒。
- **追问目标**：启用比例缩放因子 $s$，验证内角与形状相似不变性，同时观察面积按 $s^2$ 倍率放大。
- **信件**：后来的人：别只问事物走到了何方，看看它在经历万千变换之后，依然固执保留着什么。
- **公式**：旋转矩阵 $\begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$，相似面积比 $S' = s^2 S$
- **模型边界**：二维欧氏平面仿射变换，不含透视投影畸变。

### M07 几何回廊 · 几何关系
- **人物**：欧几里得（EUCLID），古希腊
- **地标**：几何回廊
- **危机对白**：“丢掉你的直觉绳索。从最不可置疑的几条公理出发，我们能在沙地上立起整座宇宙的秩序。”
- **初见目标**：用直尺与圆规作图，验证三角形三边刚性约束及任意三角形内角和恒为 $180^\circ$。
- **追问目标**：在直角三角形三边外接正方形，完成面积剪拼，重现实体勾股定理 $a^2 + b^2 = c^2$。
- **信件**：后来的人：最坚不可摧的堡垒，往往由最朴素的公理一砖一石筑成。
- **公式**：$\angle A + \angle B + \angle C = 180^\circ$，$a^2 + b^2 = c^2$
- **模型边界**：平直欧几里得空间，忽略球面或双曲曲率效应。

### M08 向量石桥 · 向量表示
- **人物**：哈密顿（WILLIAM ROWAN HAMILTON），19 世纪爱尔兰
- **地标**：向量石桥
- **危机对白**：“河水向东奔涌，你若只管向北划船，暗礁便在对岸迎候你。方向本身就是一种力量。”
- **初见目标**：水流速度 $v_w = 3$，调节船桨航向角与推进速度，使合速度矢量 $\vec{v} = \vec{v}_{船} + \vec{v}_{水}$ 正对彼岸码头。
- **追问目标**：将运动拆解为垂直过河分量与顺流平行分量，优化过河时间与航程消耗。
- **信件**：后来的人：在汹涌的逆流里，低头奔跑毫无意义。把力道分解，才能看清通向彼岸的正道。
- **公式**：$\vec{v}_{合} = \vec{v}_{船} + \vec{v}_{水}$，$|\vec{v}| = \sqrt{v_x^2 + v_y^2}$
- **模型边界**：匀速水流场，无湍流漩涡扰动，船体视作质点。

### M09 变化水钟塔 · 变化率
- **人物**：莱布尼茨（GOTTFRIED WILHELM LEIBNIZ），17 世纪德国
- **地标**：变化水钟塔
- **危机对白**：“一小时漏了三升水，可刚才那一刹那究竟有多快？把时间的缝隙缩得足够小，瞬时的秘密就会显露。”
- **初见目标**：对下降曲线取割线，将时间步长 $\Delta t$ 从 4s 逐步缩小至 0.1s，观察割线斜率收敛到瞬时切线斜率。
- **追问目标**：在水位流速转折点寻找斜率为 0 的极值点，理解瞬时变化率与驻点关系。
- **信件**：后来的人：不要畏惧无限微小的瞬间。正是每一刹那不可觉察的倾向，汇聚成了翻江倒海的浪潮。
- **公式**：$\frac{dy}{dx} = \lim_{\Delta x \to 0} \frac{f(x+\Delta x) - f(x)}{\Delta x}$
- **模型边界**：连续可微光滑水流函数，排除气泡与表面张力引起的不连续扰动。

### M10 星空测绘所 · 数学建模
- **人物**：高斯（CARL FRIEDRICH GAUSS），19 世纪德国
- **地标**：星空测绘所
- **危机对白**：“观测总有误差，云雾总会遮蔽星光。但只要假设合理，少数杂乱的亮点中也能算准整片天穹。”
- **初见目标**：面对带有测量噪声的三个离散观测点，调节理论曲线参数，使残差平方和（$\sum (y_i - \hat{y}_i)^2$）达到最小。
- **追问目标**：在不过拟合噪声的前提下，利用建立的轨道方程外推计算小行星重返夜空的预报角，并在新数据中得到验证。
- **信件**：后来的人：模型不是现实的笨拙拓印，而是对本质规律的精巧提纯。在误差中寻找秩序，在有限中预见未来。
- **公式**：$\min \sum_{i=1}^n [y_i - f(x_i; \boldsymbol{\theta})]^2$（最小二乘准则）
- **模型边界**：二体开普勒轨道投影简化，高斯误差分布假设。
