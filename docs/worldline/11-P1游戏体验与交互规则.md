# P1 游戏体验与交互规则

日期：2026 年 10 月 19 日。阶段：P1 设计交付。依据：[第三版世界线](./README.md) 与 [实施计划](./10-游戏与关卡重构实施计划.md)。

本稿确定后续关卡设计与实现需要遵守的体验规则，并配套 [可交互线框原型](./prototypes/p1/index.html)。原型使用独立的示意数据，演示地图、三个首章现场、记录成本、归档与首航回条；不替代正式模型，也不读取或修改现有游戏存档。

P1 完成的是体验规则、用户路径和界面设计。三十关详细操作在 P2 细化，实际叙事系统在 P3 接入，首章完整制作在 P4 验收。

## 这款游戏给玩家的承诺

你是一名新信使。别人遇到一个具体问题，你可以先试着摆、拖、转、连，看到事情怎样变化，再把确实弄清楚的部分寄出去。后来对方会拿着用过的结果回信。

玩家每次进入都应能回答六件事：

| 问题 | 界面怎样回答 |
|---|---|
| 我正在帮谁 | 当前委托写收件人，人物在场景或回条中出现 |
| 眼前要做什么 | 舞台边只保留一句当前目标 |
| 我能操作哪里 | 对象有抓取或选中反馈，另有同义的键盘与控件入口 |
| 刚才发生什么 | 动作即时改变现象、读数和短反馈 |
| 什么时候付出成本 | 正式记录按钮旁预先列出时间、器材成本 |
| 这份成果有什么用 | 归档卡写使用者，交付后回条指向对应成果 |

新玩家默认使用助手偏好，不先选择职业。角色偏好在信袋设置中可选，改变下一轮研究的资源配置；已有进行中的研究不因切换偏好重算。

## 两种主要视角

### 大地图

地图承担“想去哪里、为什么去、世界变了什么”。可查看群岛与当前岛的地标，但都属于地图视角。点明确地标或委托签直接进入现场，不强制先阅读地点介绍。

桌面布局由一张占主要面积的海图、一张轻量委托单、顶部常用入口和底部邮路进度组成。当前任务突出，其他现场仍可访问。

- 委托单：标题、收件人、三个所需成果、已有状态。
- 地标：地点名、当前问题及是否已有有效成果。
- 路径：当前推荐线与已建立的联系，避免所有关系同时等亮。
- 常用入口：信袋、手记与地图中的邮局。
- 交付入口：成果齐备时在委托单出现；可从刚完成的现场直接触发，不要求多走一趟邮局页面。

初次访问只揭示地点和关系，研究成立才使对应地标恢复颜色。章节交付再改变船、窗口、来往路径与人物生活。整座岛的完整复色与全部现场完成对应。

### 关卡现场

关卡承担“动手、看变化、留下记录”。主体舞台保持存在，参数、图案、读数、短对白与记录面板局部更新。

桌面舞台及控件约占内容宽度的三分之二；人物与当前目标在右侧。窄屏改为舞台在前、控件与记录在后，主要操作按钮保持易触达。

- 舞台：可操作对象、即时现象、必要标尺与给定条件。
- 操作区：优先让对象本身可操作，按钮、滑块等提供准确且可访问的同义操作。
- 目标与同伴：人物形象、一句当前问题、一条最新回应。
- 研究区：当前资源、正式记录成本、两种条件的已有证据。
- 临时反馈：失败原因或成功变化就地显示，不用新的整屏结果页挡住舞台。
- 离开：随时回地图，已有记录与进度保存。

### 邮局、信袋与手记

| 入口 | 包含什么 | 出现方式 |
|---|---|---|
| 邮局 | 当前交付、桌角、回条绳、章节后的生活 | 地图地标打开侧面板；交付不必以打开它为前置 |
| 信袋 | 委托成果、未交付项、00 回信、可选偏好 | 从任一视角打开同一个轻面板 |
| 手记 | 正式记录、比较、推理、修订、回条与史料 | 在当前视角上打开轻面板，关闭回到原处 |
| 资料卡 | 单个人物或模型的补充说明 | 手记中的自愿阅读内容 |

一次只打开一个面板，切换内容不叠弹窗。关闭或 Escape 回到先前视角与焦点。正在调节的参数不因查看信袋丢失。

## 第一段用户路径

### 新玩家

1. 邮局开场两轮内交代借桌角和四箱货，货单上能看到小禾署名。
2. 地图提供“去码头看看”，也允许先去样品台或测绘台。
3. 进入现场，短开头在舞台旁出现，立即能操作，也可主动跳过。
4. 免费调试，观察现象；选择正式记录时才支付已显示的成本。
5. 第一条件取得支持，舞台就地给出明示的新条件；玩家可继续比较，也可进入新条件。
6. 两阶段资料足够后，在原界面核对生成的说明并归档，不再打开一轮角色、知识或操作确认。
7. 当地地标复色、成果进入信袋；可以继续自由观察或直接去另一个缺项。
8. 三项齐备，从地图或现场发起一次共同交付，短演出可跳过。
9. 小禾的缺角箱回条出现，说明器材被使用，并提出夜间回寄需要。
10. 00 根据真实成果生成第一部分，玩家可换引用或直接使用默认稿。

单关归档与章节交付是两次不同动作。P01 归档只代表船的记录齐备，不能提前让四箱货到达。

### 老玩家与提前探索者

- 保留有效完成、最佳星级和历史成果，不因新版重做一遍。
- 缺少原始参数时展示“已有完成记录”，不生成虚假操作与读数。
- 章节齐备但未交付：提供整理已有记录的短桥段，直接开放交付。
- 提前完成后段：成果暂存，故事到该段直接使用；不提前播放未来的争论。
- 已交付后重访：开头承接使用结果，允许自由观察、改进记录与追加回条，世界不倒退。

## 单关内的节奏

| 时刻 | 玩家能做的事 | 界面规则 |
|---|---|---|
| 进入 | 操作、听短开头或跳过 | 不要求先选身份或读历史 |
| 自由探索 | 任意合法调节、暂停观察、恢复初始设置 | 不扣资源、不进正式失败次数 |
| 准备记录 | 查看成本，可选预判或比较对象 | 保留在控件旁，不跳新页面 |
| 正式记录 | 保存一次带条件和结果的记录 | 成本只结算一次，反馈与记录同时更新 |
| 已有支持 | 继续比较或进入明示新条件 | 不强制立刻换幕；同一舞台延续 |
| 新条件 | 看清改变的条件，再试 | 判定前说明变化，提示可回看旧记录 |
| 整理说明 | 核对引用、判断和范围，归档 | 预选相关真实记录，玩家可查看与修订 |
| 完成后 | 回地图、去缺项或继续自由观察 | 已成立成果与历史荣誉保留 |

“整理说明”是同场景中的一个小面板，不是每关最后再加一套独立选择题。系统可以整理记录，不替玩家编造一般证明或未经支持的解释。具体判断操作由 P2 按学科设计。

## 资源与错误规则

本节是后续实现的目标规范。时间是研究额度，不是现实秒数。器材代表本轮可正式使用的份额。现有内部 trust 字段对外表述为“记录可靠度”，不代表人物对玩家人格的评价。

### 初始资源

| 下一轮偏好 | 时间额度 | 器材 | 记录可靠度 | 特点 |
|---|---:|---:|---:|---|
| 助手，默认 | 9 | 4 | 2 | 较充足的整理与核对时间 |
| 工匠 | 7 | 6 | 2 | 首次正式记录不耗器材 |
| 求真者 | 7 | 4 | 3 | 初次付费核对提供更强调查支持 |

新研究采用此表。当前数学旧局的求真者初始时间与此表有差异，迁移时按旧事件语义恢复，不偷偷增减其已发生的资源消耗；P3 需要明确新旧规则版本。

### 每个动作的成本与反馈

| 动作 | 时间 / 器材 | 可靠度 | 说明 |
|---|---|---|---|
| 拖动、观察、免费操作提示、查看手记 | 0 / 0 | 不变 | 免费提示先指出可观察处，不自动授予证据 |
| 普通正式记录，无论成功或失败 | 2 / 1 | 成功通常 +1，失败 -1 | 工匠首次器材为 0；重复相同成功记录不叠可靠度 |
| 当前条件首次合格比较 | 1 / 0 | 按真实记录结果结算 | 必须确有适合该学科的合法比较，不能只点“对照”获得折扣 |
| 主动请人物核对记录 | 1 / 0 | 按现有调查规则结算 | 属于明确标价的研究动作，与免费提示区分 |
| 核对说明并归档 | 0 / 0 | 不因重复点击额外扣减 | 证据或范围不足就地说明，不发放有效成果 |
| 一次补给 | 增加 4 / 2 | 不变 | 本轮最多一次，条件和星级影响预先可见 |

可靠度范围为 0—5。预判与观察不一致不自动视为失败；正式记录是否失败取决于本关明确的声明和证据标准。一次成功观察可以帮助修正原先的猜想。[P2 细化规则](./12-P2三十关玩法设计.md) 将记录有效、目标成立和研究质量分别判定：如实记录的阴性参考可以有效，但不自动完成主目标；正式声明得不到证据支持才按失败结算。这是后续新规则，旧事件不追改。

更改 C01 身份标签、修改解释文字等不改变实验条件，不享受比较奖励。数学的比较、推导与证明也不能被一次试例取代。

现有“快速试探”“暂不行动”等入口退出主流程，可保留在进阶选项或历史回看中。是否继续暴露给玩家在 P2 逐关评估；旧事件回放仍需兼容。

### 失败与恢复

| 情况 | 反馈与恢复 |
|---|---|
| 参数暂时不满足目标，只在观察 | 展示现象，允许继续调；不扣资源 |
| 正式记录不成立 | 保存条件和结果，扣本次已显示成本，可靠度 -1；说明可检查之处 |
| 解释超出支持范围 | 不归档有效成果，保留证据与已经支付的成本，允许就地修订；不按连续点击刷罚 |
| 额度不足，且无可负担的合格比较 | 提供一次补给；预先说明本轮不满足三星无补给条件 |
| 补给已用仍不足 | 可以开启新一轮研究，恢复所选偏好初始资源；本轮正式记录转入可回看的既往尝试 |
| 可靠度为 0 | 可通过新的成功核对恢复；若当前阶段没有合法恢复动作，明确提供新一轮研究 |
| 已完成关卡重玩失败 | 当前研究承担自己的成本；已交付成果、世界变化与历史最佳保留 |

新一轮只重置当局资源与评分依据，既往尝试保留来源，不跨局搬运证据拼成新的三星。复用同一条已经成立的成果，也不能重复刷章节奖励。

人物回应具体记录，不评判聪明与否。成本不会变成居民受伤、失业或永久不再理会玩家。

## 正向激励与星级

### 四种反馈

| 时间 | 玩家得到什么 |
|---|---|
| 操作当下 | 水线、船、图形、粒子示意或读数立即改变 |
| 留下有效记录 | 一张带真实条件的小卡，人物指出这次可用的部分 |
| 归档与交付 | 当地复色、船出港、窗口接班，以及收件人的具体回应 |
| 之后回访 | 用过的图、追加回条、共同修订和自己的邮局位置 |

不新增强制日常签到、通行体力或伙伴养成。角色关系由共同经历变化，不靠反复送礼或刷同一实验。

### 三星的作用

星级是可选研究表现，提供清楚且稳定的目标，不是进入后续剧情的钥匙。

| 星 | 对外含义 | 判定方向 |
|---|---|---|
| 第一星：成果成立 | 说明得到足够支持，范围合适 | 有效结局；与当前可信完成语义兼容 |
| 第二星：亲手核对 | 两种条件都有本人有效记录 | 适配学科的操作与依据，不能只靠调查替代所有动手 |
| 第三星：比较研究 | 有合法比较且研究过程扎实 | 前两星成立、存在合法比较、正式失败不超过 1 次、未用补给 |

每科“合法比较”的具体标准已在 [P2 玩法卡](./12-P2三十关玩法设计.md) 写明，包括控制比较、交叉取证、表示核对、推理与独立检验，各用专属判据。数学一般命题仍需要推导或证明。预判不是三星的必填条件，免费提示不自动扣星，一次有意义的正式修正也不必失去三星资格。

展示本轮表现与历史最佳的区别，最佳只升不降。补给不影响第一、第二星与主线推进。主界面不再鼓励收集四种失败或成功结局；旧结果保留在手记。

## 人物、故事与提示

- 每次进入都有开头，初见、已有记录、已交付与重访使用不同内容。
- 同一时间最多一条主要对白；短回应随操作出现，不抢走滑块和键盘焦点。
- 阿墨提醒变化与提问，研究伙伴提供具体方法，收信人通过使用结果回应。
- 成功话语由实际结果触发；故事旧稿差异不追认玩家的正确记录为错误。
- 免费提示逐级指出现象、可比条件和下一步；完整依据自愿展开。
- 历史卡与创作对白分别标识，重要模型条件留在当前判断附近。
- 演出跳过仍写入对应回条与任务摘要，可从手记重看。

普通气泡以一两句为主。长生平、推导和资料不放在首次操作前连续播放。

## 交付、00 回信与结局

当本章三项有效成果齐备，地图委托单、信袋和当前关卡完成区都能发起同一次交付。只能首次交付一次，重看演出不重复结算。

回条只引用真实完成内容。支线晚补寄追加回条，主线不倒退。旧档缺少参数时用中性完成描述。

00 以真实记录生成默认稿，允许换引用和附上已有修订过程，未选择也能寄出。不要求个人输入、不强制失败、不引入额外考试。

结尾保留玩家桌位、阿墨搭档和已恢复的邮路。新人的问题用于开放下一段生活，不变成主结局后的强制新任务。

## 视觉与可访问性

主调为海图冷蓝、纸白、深墨色；邮戳和纸夹用少量清楚的强调色。已建立联系的地标局部恢复原色，其他区域保留冷蓝。

内部配色随场景变化：码头的木色与海水、样品台的浅色纸面和玻璃、测绘台的深色图板与亮色图形。保留统一像素尺度与信息层级，不给全部关卡覆盖蓝色滤镜。

- 正文以清晰中文字体为主，标题可使用有手稿感的衬线字；不把长文做成难读像素字体。
- 桌面主要舞台占据视觉中心，观察优先于统计。
- 主要操作支持键盘，焦点清楚；关键状态同时有图案或文字。
- 面板支持 Escape、焦点返回、窄屏滚动；不让横向溢出遮住按钮。
- 支持减少动态效果，声音不承载唯一信息。
- 静音、减少动画、跳过演出不改变研究与故事状态。

## 原型的评审范围

原型可体验：

1. 地图直接进入三个首章现场，及每次进入的短开头。
2. 即时控件、免费观察、正式记录成本与错误反馈。
3. 明示新条件、保留舞台、归档成果和当地复色。
4. 三项齐备后的直接交付与小禾回条。
5. 信袋、手记、邮局单层面板，以及新旧记录评审预设。
6. 独立示意进度的保存、恢复和重置。

原型的船体、性质与坐标表现用于验证交互和信息层级，不作为正式科学仿真；没有实现的研究比较、角色特性和后续章节不假装已经完成。P2 与 P3—P4 再按上述完整规范接入正式数据、规则和模型。

P01 在原型中演示合法比较与折扣；C01、M03 的比较星在 P2 细化，本原型不推定授予第三星，不代表正式关卡不能取得三星。完整角色差异也不在本原型中模拟。

评审工具条里的“已有记录”“三项齐备”等是明确标注的设计预设，不是正式游戏中的跳关功能。原型保存使用独立键，不污染现有玩家进度。

## P1 验收与进入 P2 的条件

| 检查项 | 验收口径 |
|---|---|
| 目标清楚 | 开场后能指出小禾、四箱货与当前可做动作 |
| 两种视角 | 地图与现场可往返，面板不叠加成第三条必经流程 |
| 立即可玩 | 不完成身份、历史与操作确认也能开始调试 |
| 成本可预期 | 免费与正式动作清楚，记录前可见具体成本 |
| 失败可恢复 | 正式失误有成本与可查原因，资源耗尽仍有出口 |
| 奖励有用途 | 成果进入同一批货，回条能对应自己的操作 |
| 星级不锁剧情 | 主线不要求三星或补充委托，最高荣誉保留 |
