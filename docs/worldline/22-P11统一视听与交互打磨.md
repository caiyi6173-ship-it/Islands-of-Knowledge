## 让三座岛像同一款游戏

关卡继续使用自己的场景色彩，地图仍按有效研究逐步从冷蓝复色。统一的是标题、肖像画框、数值布局、按钮、键盘焦点与反馈，不增加新的进关步骤。

三科历史人物保留原有像素特征，使用相同尺寸、基线与边框。老乔、阿澜和小禾在章节条中直接复用邮局及演出的像素人物；阿墨继续出现在开头、交付和伙伴场景中。人物形象与对白均属教学创作，不作为真实肖像或历史原话。

## 不靠颜色和声音猜结果

| 情形 | 视觉提示 | 短音效与结算 |
|---|---|---|
| 自由操作 | ◇ 自由试验；即时反馈与读数 | 不扣资源，不给滑条连续配音 |
| 目标获得支持 | ✓ 目标有支持 | 短上行和弦；按原规则保存正式记录 |
| 有效参考，尚未支持目标 | ▤ 参考已保存 | 两个轻音；不冒充目标完成，也不算正式失误 |
| 操作或证据仍需核对 | ! 还需核对 | 正式命令被拒时用短提示；免费非法操作不制造结算 |
| 正式声明未成立 | × 正式声明未成立 | 低声下行音；显示这次时间、器材与实际可靠度变化，并提示可以免费调试 |
| 成果归档 | ✉ 成果已收好 | 较完整的短和弦；保留单关成果与章节共同交付的区别 |
| 回条到达 | 回条正文、收件人和实际寄出版本 | 单次到达音；重绘和选择 00 来源不反复播放 |

根据现场的浅色或深色底色选用反馈色。三十关的成功、参考、警告和错误文字对比度均通过 4.5:1 检查。颜色外还有文字和符号，静音时也能理解结果。

可见预览对白不再是每次变化都播报的 live region。正式结果使用单独的礼貌播报区，滑条不会反复打断读屏。完整辅助技术实际体验仍需 P12 进一步人工检查。

## 操作不被反馈打断

保留舞台和原生控件，只更新条件、参数、读数、结果与手记。结果提示使用 220 毫秒的分步淡入，不盖住舞台。交付画面、图册和回条有轻量纸页过渡。

每次进关仍出现对应开头；取消原先 6.5 秒自动收起，玩家可以读完再点“开始动手”、按 Escape，或直接操作。跳过后焦点移到第一个可操作控件。正式提交使按钮失效或消失时，焦点移向后续任务或实验控件。

滑条改为“完整标签与数值一行，滑条另占一行”，避免长单位被挤成竖排。窄屏顶部按钮与标题分行，主操作按钮、分类按钮及滑条使用至少 44 像素高的触控区域。三十关在 320 像素宽度下无横向溢出；地图、手记和回条沿用既有入口。

C07 的两支分量与非零合量增加可见箭头尖端，平移对应继续使用虚线。零合量不画有方向的假箭头，非零分量保留；参数、公式和正式判断没有改变。

## 声音与动画的生命周期

共用音效延迟创建 AudioContext，新的结果音替换尚未结束的旧提示，避免叠加。保留既有静音设置。关卡和回条都可直接静音；静音、窗口失焦、页面隐藏和退出会停止共用提示。静音变更会通知琴弦、电键等自有音频运行时，取消正在发声及尚未开始的音符。跨页静音设置同步到当前按钮。

系统“减少动态效果”在关卡打开期间变化也会立即生效：

- 停止环境运动、船与轨迹播放、变换回放和提示过渡，不停止玩家亲手输入的物理采样或即时计算。
- P02 放球、P04 落锤用静态终态表达结果，时刻、温升等读数仍可见。
- 交付演出的自动翻页停止在当前幕，玩家可以手动继续或直接跳过；已经保存的交付与引用版本保持不变。
- 系统偏好开启时，动画按钮明确显示“已按系统减少动态”，关闭该偏好后恢复手动控制。没有系统限制时，也可以单独暂停场景动画。

所有新监听、动画、观察器及自有音频在退出时清理。原规则正在进行的记录继续通过原有兼容入口使用，不在这一阶段改写旧事件。

## 实现与后续

`research-presentation.js/css` 负责共用呈现，`first-voyage-workbench.js` 负责原有研究流程，学科插件继续拥有各自模型和操作。`physics-sound.js` 集中合成与取消短提示；电键、琴弦保留各自输入与声音逻辑。

验收入口：`npm run check:presentation`、`npm test`、`npm run test:browser:presentation`，并复跑九组已有浏览器回归。测试使用独立端口和隔离浏览器上下文，不写玩家在 4173 端口的存档。

下一阶段 P12 按完整流程检查新旧档、任意访问顺序、重做、重置、跨页保存、结局后补寄，并收集真实玩家对任务、证据、回条与结尾的理解。自动测试通过不等于玩家已经觉得有趣。
