# P2 首章三关交互规格

设计日期：2026 年 10 月 19 日；实现更新：10 月 20 日。状态：**P01、C01、M03 已在 P4 接入正式入口**，实现范围与证据见 [15 首航实现与验证](./15-P4首航实现与验证.md)。配套 [12 三十关玩法设计](./12-P2三十关玩法设计.md)、[P1 通用规则](./11-P1游戏体验与交互规则.md) 和 [R01 演出样章](./06-首航三岛完整样章.md)。

## 玩家实际经过的流程

邮局看到“四箱，寄给小禾” → 任意顺序进入三个现场 → 免费操作 → 正式记录第一条件 → 可继续研究或进入明示新条件 → 第二条件核对 → 就地收好成果 → 三项齐备后共同交付 → 小禾寄回缺角箱回条。

第一轮建议每关约 3—6 分钟，额外研究再留 1—3 分钟。它是需要试玩验证的节奏目标，不是已测得时长，不设倒计时。无须先选角色、读历史、填写预测或完成知识测验。

### 一张持续存在的实验台

| 区域 | 桌面 | 窄屏 |
|---|---|---|
| 顶栏 | 返回、任务与可展开资源、静音 | 同样内容压缩为一行，详情可展开 |
| 主舞台 | 装置/地图占主要面积，人物气泡靠边 | 舞台在上，尺寸固定，不因读数变长跳动 |
| 操作与读数 | 一块紧凑区，输入旁立即显示相关结果 | 在舞台下顺排，主按钮可见，不遮住拖放区 |
| 记录条 | 时间顺序小卡，可对比、回看来源 | 横向卡条或纵向展开，整页不横溢 |
| 收好成果 | 条件满足后在原位置展开摘要 | 同页展开；不是新页面或多层弹窗 |

关卡内部保留丰富主题色：码头木色、海绿与帆白；样品台纸白、玻璃青与铜铁色；测绘台深墨、粉笔白与橙绿图形。地标复色只作用地图，不给关卡罩蓝色滤镜。保持统一像素尺度与按钮语言。

输入只更新参数、读数和相应图层；气泡不抢焦点。打开记录、跳过开场、换条件均保留舞台实例。失焦、开面板与退出时暂停会产生正式时间片段的采样，不把后台时长算成玩家操作。

## 共用状态与记录语义

下表使用设计状态名称；运行接口与字段映射见 P3、P4 的实现记录。

| 状态/事实 | 进入条件 | 玩家下一步 |
|---|---|---|
| 短开场 | 每次进关，按初见/已有成果/已交付选版本 | 可操作或跳过，不依赖播完写进度 |
| 条件一探索 | 当前参数合法 | 免费操作或正式记录 |
| 条件一有支持 | 目标记录成立 | 留在本条件比较，或进入已明示的新条件 |
| 条件二探索 | 玩家主动切换 | 免费操作、记录、回看旧条件 |
| 可归档 | 两条件所需依据与范围齐备 | 可核对可选研究，或直接收好 |
| 已归档 | 本地成果有效 | 去实际缺项、自由探索或共同交付 |
| 已交付后重访 | 章节交付事实存在 | 承接使用结果，改进记录不倒退世界 |

第一条件有支持后不自动删掉当前控件。进入第二条件后，也可点记录条的“回到此条件核对”进入明确的补充研究模式，保留第二条件进度；完成后返回。它不重播开头、不新增长任务层级，不把新记录伪装为过去已发生的事件。

归档前始终显示第三星要求、已有依据与一个明确的“补充核对”入口。归档后自由操作仍免费；要提高本轮表现，可在同一未重置研究中追加核对并发布成果修订，保留版本和引用，不重复发章节奖励。开始新研究后不能借旧轮实验拼新三星；旧成果只用于故事承接和查阅。

### 一次正式提交必须是完整事务

提交时快照当前条件与输入，核验合法性，计算结果，按同一规则结算一次成本，追加记录，再局部展示反馈。重入、双击、重放同一事件、离开后的异步回调都不得重复结算。预览结果不充当正式证据。

记录应带：本轮 ID、记录 ID、关卡/条件 ID、规则与模型版本、实际输入、固定条件、计算结果、来源、声明、有效性、目标支持情况、成本、时间顺序。补充研究还带引用记录 ID、研究方式与核验结果。虚构教学资料标 `given`，玩家本轮记录标 `player`；旧档仅有完成标记则保持为无原始参数的旧成果。

| 字段类别 | 首章例子 | 能否单凭改变获得研究奖励 |
|---|---|---|
| 实验条件 | P01 形状与给定载重 | 还须有控制条件和正式结果 |
| 测量程序 | C01 密度/电导/磁响应 | 还须有相应区分力和交叉依据 |
| 构建/表示 | M03 局部坐标、原点、斜率 | 还须核对转换或代入，不按改键数打分 |
| 判断 | C01 身份签、对结果的声明 | 否；修订判断不制造新测量 |
| 视图 | 放大、镜头、展开读数 | 否 |

普通正式记录 2 时间、1 器材；首次符合本条件研究优惠的补充记录 1 时间、0 器材。资格与费用在提交前展示，判断错仍按已报价费用和正式失败规则处理，不能事后再加收差价。条件与声明完全相同的重复提交提示“已有记录”，不再扣费或奖励。修改身份后再次正式核对属于新判断，引用原有测量事实并按已报价的记录成本结算，不制造新的独立测量，也不取得比较优惠。免费提示、暂停、回看和归档不收费。

正式不成立的声明消耗本次费用、可靠度 −1，保留依据。有效参考或阴性记录不扣可靠度；它可以支持比较，但不冒充主目标成立。可靠度奖励对同一研究事实去重。范围不足的摘要就地说明并允许修改，不用重复点按钮刷罚。

## P01：先让同一块材料承载起来

### 开场与舞台

潮汐港小水槽在前景，四箱货停在干燥码头。阿基米德站水槽旁，阿澜的真实船处于备航状态。开场不超过两轮：

> 阿基米德：“先不装箱。还是这块材料，看看形状变了会怎样。”
>
> 阿墨：“船口和水线，先看哪一个？”

人物问题不要求作答。玩家已经可以拖模型、用键盘选形，再按放入水槽。进入时可以默认实心形，预览下沉不扣资源。

### 参数与反馈

| 项 | 本次规格 | 当前模型情况 |
|---|---|---|
| 形状 `shape` | `lump` 实心 / `bowl` 碗形 / `wide` 宽船 | 已有，最大排水容量分别 0.9 / 4.2 / 6.4 L |
| 材料质量 | 固定 1.2 kg，塑形不能改变 | 已有 |
| 第一条件载重 | 空载，`cargo=0` | 已由当前轮次固定 |
| 第二条件载重 | 四箱，每箱 1.2 kg，`cargo=4` | 已有，总质量 6.0 kg |
| 水的密度 | 本教学模型固定 1 kg/L | 现有公式隐含，新增显式条件 |
| 拖放与塑形 | 从三种形状卡拖入/吸附成模型；键盘等价操作 | 新增表现，不新增连续船宽自变量 |
| 参考显示 | 水线、进水边界、最大容量、总质量 | 新增规范标注与图层 |

不显示“浮着时浮力比重力更大”。静浮时实际排水量为质量除以水密度，最大容量是进水前上限。宽船载货：6.0 kg，对应实际排水约 6.0 L，最大 6.4 L，容量余量约 0.4 L。船体画法应让水线随该关系变化；未建立船体几何体积函数前，使用分段示意刻度，不标未经计算的真实吃水厘米数。

装箱可以用四次短动画表达，但主条件始终是“空载”与“四箱全载”。当前模型未把 1—3 箱作为独立正式条件；不得把动画中间帧当作正式测量或额外完成要求。

### 第一条件：空载

1. 调形与入水免费；每种形状显示实际容量和浮沉。
2. “记录空载可承载”显示费用。碗形、宽船均能支持，实心不能。
3. 成立后吃水卡出现“空载”；原舞台和当前形状保留。
4. 同时可见两个动作：“比较另一种空载船型”与“检查四箱载重”。可先做任一个，不把额外比较藏在下一幕以后。

### 新条件：四箱

阿澜指向四箱：“刚才没装这些。重量变了，再查一次。”条件条先写出 6.0 kg，然后才开放新记录。保留先前形状，若原先是碗形，就让预览如实显示容量不足，不偷偷换成宽船。

宽船可支持本关承载目标。碗形的预览下沉免费；正式声称“可承四箱”却不成立才扣费与可靠度，反馈显示“6.0 kg / 最大排水 4.2 L”，并提示看船口容量。模型事故不发生在阿澜的真实载人船上。

### 可选第三星：同材料、同空载，比较两种浮船

引用一条空载碗形记录，再留空载宽船记录（顺序也可反过来）。固定材料、水、载重；确认容量改变而材料质量未变，水线表现与记录一致。两条均可有效，不必提交实心下沉作为失败记录。

若第二次同时切换为四箱，不能算“空载形状比较”，但可成为第二主要条件的普通记录。费用、研究资格及需要补哪一组，在点击前就说明。

### 吃水卡与当地结果

卡上引用本轮真实空载、四箱记录，写明形状、质量、容量与未检验条件。不让玩家再背一遍浮力定义。收好后对应码头复色、阿澜备船，货物仍在岸上；任务只勾承载项。已有 C01/M03 时直接承接，否则指向实际缺项。R01 交付后重访展示装载卡的使用，不再搬回“最后一箱”。

## C01：名字贴在证据之后

### 开场与舞台

地点是化学岛**标本港入口样品台**，不是小禾的内港观测窗口。玩家带清单副本和密封虚拟留样，整批四箱仍待发航。桌上有 A/B 留样、仪器位、参考卡和身份签。

> 波义耳：“外面两张签泡坏了。先看哪一项性质能分开。”
>
> 阿墨：“名字先放旁边。测完再夹回去。”

拖样品到仪器位，或点选仪器，读数立即出现。系统不演示真实未知物取样操作；所有对象均是限定候选的虚拟样品。

### 数据与字段

| 条件 | 真实对象 / 候选 | 观察或测量 | 能否区分 |
|---|---|---|---|
| A | 盐；参考为盐/糖 | 外观：白色晶体 | 不能 |
| A | 同一 A | 密度：2.16 g/cm³；参考糖 1.59、盐 2.16 | 在给定资料中能 |
| A | 同一 A 的规定虚拟溶液 | 电导相对值 15；参考糖 0.2、盐 15 | 在给定条件中能 |
| B | 铁；参考为铁/铜 | 外观近似，或仅观察可导电 | 不能 |
| B | 同一 B | 明显被磁铁吸引；参考铁明显、铜无此响应 | 在给定资料中能 |

沿用现有教学数值，不声称它们是本次新测量的真实物性标准。密度对应固体参考，电导对应规定虚拟溶液。新增固定条件说明：“各自采用参考表同温度；电导比较为相同规定浓度与装置”，内部使用明确条件 ID 与参考版本；未给数值的条件不伪造实际温度/浓度。正式内容接入前，要使参考、样品和装置确实共享该配置。

现有 `instrument` 分别取 `eye/density/conductivity`、`eye/conductivity/magnet`；`identity` 分别是 `sugar/salt`、`copper/iron`。前者是测量程序，后者是判断。无论身份签放在哪里，A 的密度都不变，B 的磁响应都不变。

### 第一条件：A 的身份签

1. 预览外观或仪器读数免费。参考卡直接放旁边，查看不收费。
2. 玩家把身份签夹上，主按钮为“记录测量与身份”；没有仪器依据也可尝试，但明确提示“外观不足以区分”，不能偷放行。
3. 密度或溶液电导与盐参考对应，且身份为盐，才支持此目标。
4. 成立后保留装置，可用另一种有区分力的测量做交叉核对，也可进入 B。

### 新条件：B 的身份签

切换前明确“另一份留样：金属 B；候选铁/铜”。不沿用 A 的参考表。仅记录金属导电，无法排除两个候选；磁响应和正确身份共同支持目标。

正式使用不足以区分的测量、或贴错身份，保留读数与声明，支付所示成本、可靠度 −1。反馈分别指出“参考两边都可导电”或“读数指向另一候选”，不笼统弹“回答错误”。玩家可免费移动签、换仪器；只有再次正式记录才有成本。

### 可选第三星：同一样品的交叉取证

必须满足以下全部条件：同一 A 与同一参考版本；本轮已有一条有效身份记录；另一条采用不同的有区分力方法；两种测量各自条件明确；两者指向同一候选；玩家身份判断与其一致。

密度→溶液电导或反向都可。外观→密度不算双证据；金属电导→磁响应也不算两种都能排除候选。只改身份标签不产生新的测量事实，不享受研究优惠。

新记录保存规范字段，例如样品 ID、测量方法、数值与单位/响应、条件 ID、参考版本和可排除的候选。当前密度数值仅在格式化读数字符串中出现，必须在适配层补结构化结果，不能从显示文本里临时截数字做评分。

### 样品签与当地结果

摘要直接展示两份样品的性质、测量依据和候选范围；第三星取得时另附交叉依据。收好后样品柜复色、第四箱清单补签，不提前进入内港。R01 共同交付后，小禾回条才承接使用结果；若先做 M03 或 P01，对话只说目前真实已有的记录。

## M03：让下一位也找得到

### 开场与舞台

数学岛测绘台摆着内港网格，窗口是清晰的目标物，不藏门牌答案。笛卡尔画原点，阿墨拿着“右上一点”的旧地址。

> 笛卡尔：“从哪里数，一格多长，先放在图上。”
>
> 阿墨：“这次换个人拿图，也能找到？”

玩家直接拖投递标记或键盘逐格移动。原点、东为横轴正向、北为纵轴正向、每格一个模型长度单位始终可见，不另开确认测验。这里的格不是未经测量的实际米数。

### 参数与反馈

| 项 | 本次规格 | 计算依据 |
|---|---|---|
| 世界网格 | x 为 0—8，y 为 0—6，整数格点 | 统一舞台、输入与保存范围 |
| 窗口世界位置 | (4,3)，固定 | 不因玩家选地址或换原点移动 |
| 默认原点 | (0,0) | 当前代码固定目标可映射至此 |
| 可选核对原点 | (1,1)，方向与单位不变 | 局部坐标=世界坐标−原点 |
| 地址输入 | `targetX/targetY` 可适配为局部坐标 | 世界落点=原点+局部坐标 |
| 第一条件成功 | 世界落点等于 (4,3)，附完整坐标约定 | 整数格精确相等，不靠屏幕距离 |
| 第二条件 | 固定默认原点，给定关系族 y=mx，b=0 | 航标 (1,2)、(3,6) 不变 |
| 斜率 | `lineSlope` 为 0—4、步长 0.1 | 每点残差 y−mx；显示容差，建议绝对值≤0.01 |

换原点后合法局部坐标范围随世界边界变化，例如原点 (1,1) 时 x 为 −1—7、y 为 −1—5。输入、拖拽、存储和模型共用同一转换；不要把负坐标静默夹成零。第一版只支持上述两个明确原点，不承诺任意旋转坐标轴与比例换算。

当前数学不同模块的 targetY 上界有 6/7 差异，P4 统一为这里的世界边界；不要让舞台可选而模型截断。进入第二条件时明确换回题卡所给默认坐标系，不把可选换原点状态偷偷带进斜率判定。

### 第一条件：窗口地址

1. 拖标记可看横向、纵向步数与落点；修改任一坐标同步更新标记。
2. 主按钮“记录窗口地址”保存原点、方向、单位、坐标次序、局部坐标与还原世界点。
3. 落点正确才支持目标；(3,4) 显示投到哪里、与窗口分别差几格，不只提示“x/y 颠倒”。
4. 成立后可以直接继续航标，也能先做换原点核对。

### 新条件：航标与关系线

明确显示“这张题卡只研究过原点的直线 y=mx”，放出两个给定航标。玩家拖直线上的控制点，斜率刻度和逐点代入同步更新；选择 m=2 后，2−2×1=0、6−2×3=0。

正式核对必须保存两个点的代入依据；不是只检查参数名字等于 2。任一点残差越限就高亮该点。有限点在给定直线族中确定参数，不声称证明未知现实路径或任意函数必为这条线。

### 可选第三星：换原点，仍是同一个窗口

引用第一条件默认原点地址 (4,3)，把原点放到给定 (1,1)，重新移动或输入地址为 (3,2)。舞台仍显示同一个窗口，玩家核对 (1,1)+(3,2)=(4,3)。

研究判断基于两个坐标系还原出的世界位置相同、目标一致、方向单位一致，并有两条本轮正式记录；不是靠“只改一个键”。只移原点、不修订地址会投到 (5,4)，可免费发现；正式声称位置相同却不成立才算错误。改答案后不能保留伪造的旧落点。

### 地址签与当地结果

地址签正面是可供下一位使用的默认地址及约定，背面是航标代入；取得第三星可附另一个原点的地址对照。测绘台地标复色、窗口地图标记清楚，但四箱仍等共同交付。已完成 C01 时明确两处不同：入口样品台已经核对样品，最终投递仍到内港窗口。
