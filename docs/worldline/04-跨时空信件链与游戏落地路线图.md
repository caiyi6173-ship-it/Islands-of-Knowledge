# 三岛邮路任务与关卡改写顺序

版本：第三版，2026 年 10 月 19 日。五段故事完成同一次三岛夜邮复航。任务以 [总纲](./README.md) 为准，人物见 [01](./01-渡鸦信使与探索者档案.md)，演出见 [06](./06-首航三岛完整样章.md) 与 [09](./09-五段剧情与伏笔回收.md)。

本文件定义内容与功能目标。P3 已接入邮路货单、成果与文本回条基础；常驻人物演出、00 引用选择和新版关卡在后续阶段接入，当前实现范围见 [14](./14-P3运行基础与验证.md)。

每段的三份主线记录分别有必要用途，科学原理与作用不能互相替代。补充委托各自提供可使用的成果与追加回条，不把可选内容写成整圈复航的隐形门槛。

| R03 | 收发约定＋变换图例＋电子对图例，成为分册的使用说明 | 已清楚的分册保留，其他旧页标为待核对 | 电磁信号、几何变换、分子符号各有自己的图例 |

居民负责完整设施和日常工作。故事可以展示他们按记录修订说明、接班与回寄；不能把实验台的简化结果直接放大成超出模型的现实功用。

## 单关与段落的两次反馈

单关完成先展示一处当地变化：备航船、已补标签、图例页、模型柜或小型演示恢复。地图对应地标可以复色。成果进入同一份邮路记录。

段落交付再发生共同事件：货物抵达、夜班接应、修订稿被读懂、图册寄出、整圈返回。每段只首次交付一次，可从手记重看。

第一段推荐 P01→C01→M03，但三个现场可任意顺序。若先到标本港，玩家携带留样和清单副本，不会先把整批货物送达。已做完的环节不重新缺失。

## 回条也要有关系变化

| 邮路 | 基础回条 | 人物推进 | 补充完成后的追加细节 |
|---|---|---|---|
| R01 | “收到了。最后那箱也在。记录总要到收工才写完，晚上也能有人接吗？——小禾”附缺角箱子 | 阿墨第一次认出自己的工作被远方看见 | 时间、质量、组成清单只勾选实际补齐项 |
| R02 | “今晚轮到我们接。交班纸签夹在窗口，回程看这里。——小禾和值班同伴” | 阿澜有明确交班，老乔放出旧稿副页 | 温升、分拣或金属签说明贴在各自使用处 |
| R03 | “这次看懂了。我这边的图，也少写了一行，改稿一起寄回。——小禾” | 等待帮助的人开始帮助别人，老乔允许修订稿寄出 | 条纹、音程、分类页分别收到使用补注 |
| R04 | “用途放在正面了。新现场还没试过的部分，我们也留着。——三站图册夹” | 阿墨展开折角，小禾和老乔都留下自己的修订 | 直角依据、异常报告或偶极图作为明确附页 |
| R05 | “新记录收到了。下一轮有一处，想和你们一起查。——标本港观测窗口、测绘台” | 三站共同回信，玩家获得自己的收信格 | 能量模型、变化率、组成比较成为相应后续问题 |

未做补充时用基础版；晚些完成收到追加回条，不再重演首航。回条引用实际记录，不能编造失败、数值、三星或未做的比较。章节给定资料和玩家所得记录在手记中分别注明来源。

## 关系连线的四种含义

| 类型 | 玩家看到的理由 | 例子与边界 |
|---|---|---|
| 同一委托 | “随同一批货物或图册寄走” | P01、C01、M03；浮力不导出坐标 |
| 工具迁移 | “这里也能用刚才的描述工具” | M08、C07 的箭头相加；速度与偶极不是同一物理量 |
| 共同问题 | “换了场景，继续检查同一类问题” | C08 与 P04 都写清账目边界；质量与能量不混作同一量 |
| 历史工作承接 | “后来的研究怎样使用或回应前人的工作” | P09、P10 分别写具体贡献和年代 |

M09 与 P02 可连接变化率与运动问题，但不编成后者在历史上受前者促成。推荐航路、历史年份与概念关系分别标注。

## 故事状态及自由顺序

场景文案至少由以下事实决定：是否见面、是否拥有有效记录、当前邮路是否交付、已经发生哪次共同事件。不能从打开次数推断完成。

| 玩家情境 | 内容如何承接 |
|---|---|
| 首次进入当前推荐现场 | 短开场交代谁需要什么，立刻交出操作权 |
| 提前进入后段现场 | 处理同一份本地资料，成果暂存；不提前播放整段交付或提及尚未发生的争论 |
| 后来故事用到已有记录 | 展示核对与使用已有页的短桥段，直接计入，不要求重打 |
| 重访已完成现场 | 看使用反馈、自己的修订或合理的新比较，不让居民失忆 |
| 邮路已经交付再重做 | 可修订本地成果并追加回条，既有送达与人物进展不倒退 |
| 跳过开头与交付演出 | 任务、回条、关系变化写入可回看手记，不依赖看完视频才算触发 |
| 旧档只有完成标记 | 承认完成，采用中性概述；不伪造参数、步骤和失败次数 |
| 提前做完全部主线 | 依次开放五次交付与短桥段，可跳过演出；不重复测验 |
| 结局后继续探索 | 保留正式桌位和搭档，支线有自己的使用者与追加回条 |

五段的交付顺序固定，现场访问顺序自由。15 项主线有效完成及五次交付开放主结局；30 项完成才开放全览后记与完整复色。主结局不要求三星、故意失败或阅读史料。

## 故事不新增交互层级

每次进入仍播放可跳过的开头。通常两轮以内进入实验主舞台，目标和短对话留在舞台旁。历史卡、长推导与资料自愿打开。

段落交付是已有成果齐备后的故事动作，不再附加总测验。00 回信有基于已有记录的默认内容，桌位物件有默认选择；不操作个性化选项也能自然结束。

后续功能接入时，叙事状态与研究账本分别保存。对白展示不能直接篡改实验分数、清空已交付记录或凭空授予新测量。

## 正向激励与错误后果

免费操作提供即时现象。正式记录按现有规则结算时间、器材与可靠度，反馈必须指明条件、证据或推理问题。修订可以带来具体肯定，但不会把改答案标签当作公平对照。

故事奖励为真实成果对应的现场变化、使用者的回应、邮局留下的共同经历。无失败玩家拥有完整故事。公开已有修订是个人选择，不是额外收益必选项。

正式失误不写成居民受伤或整条邮路永久毁坏。人物可以指出后果，也需要给出可恢复的下一步。

## 内容接入顺序

### 一、先做通 R01

按 [06](./06-首航三岛完整样章.md) 接入 P01、C01、M03 的短开头、当地结果、共同货单与小禾回条。此时首先检验玩家是否说得清货物、收件人和三科的不同贡献。

### 二、接入 R02 与 R03

让回寄需要引出夜班，让使用反馈引出旧稿核对。实现人物首次与重逢变体，再补齐两张旧图、中段分歧与共同改稿。

### 三、接入 R04 与 R05

按 [09](./09-五段剧情与伏笔回收.md) 接入条件页、整圈返回、00 回信与桌位结局。结局依赖既有主线成果，不新增隐藏评价门槛。

### 四、补全支线与生活

补齐十五份补充委托、追加回条、结局后重访和三十关全览。固定日常随章节变化，不增加强制等待或维护负担。

## 内容验收

- 30 个编号各占一行，每段主线各含物理、数学、化学一关。
- 每个主线现场贡献的记录，确实在共同交付中使用。
- 玩家能说清前段成功怎样引出后段问题。
- 角色各有愿望、分歧、主动选择和回收动作。
- 六条伏笔都有初见、中途推进和回收位置。
- 单关结果不提前宣布整批送达或整圈复航。
- 自由顺序、跳过、重做与旧档都不导致已发生事实倒退。
- 回条与 00 只引用真实取得的成果，教学资料单独标来源。
- 错误反馈、模型边界与剧情描述一致，数学观察不冒充一般证明。
- 十五项主线和五次交付足以完成结局，个性化、支线与三星不额外阻塞。
