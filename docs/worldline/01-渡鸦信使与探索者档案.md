# 见习信使与渡鸦伙伴

版本：第三版，2026 年 10 月 19 日。人物与事件以 [总纲](./README.md) 为准；全部新对白与群岛关系属于本作创作，历史原型边界见 [07](./07-史实边界与资料索引.md)。

人物线围绕同一次三岛夜邮复航展开。信使负责跨岛行动与决定，阿墨负责陪伴和记忆，老乔、阿澜、小禾分别把可靠、约定与被理解的愿望带进故事。

## 玩家：从借桌角到有自己的位置

玩家刚到潮汐港邮局，希望成为正式信使。老乔交给他临时信袋、活页手记和编号 00 的回信纸，腾出桌角：“先在这里整理。”

开场愿望是能留下工作、获得自己的信袋与桌位。第一趟成功后，玩家开始期待收信人的回应；中段面对含糊的旧稿，他可以追查原件，而不仅等站长再发任务；最后，他能发出带有自己方法、条件与问题的回信。

信使的作用来自来往各站、对照原稿与使用记录。科学家帮助理解本地问题，居民负责自己的工作。决定寄哪份已有记录、怎样向对岸说明未知，由玩家完成。

### 外形与常用物品

默认形象为深蓝短外套与便于操作的信袋，允许外观自定义。人物在不同关卡受当地光色影响，不统一套蓝色滤镜。

| 物件 | 开始时 | 随旅途变化 | 结尾 |
|---|---|---|---|
| 临时信袋 | 收着空白委托与 00 纸 | 出现不同站点的小纸签，保存原件与回条 | 换上正式身份签，继续用于后续探索 |
| 活页手记 | 大部分是空白 | 留下真实设置、推理、使用反馈和修订 | 可以给新人翻看，未试条件继续留白 |
| 00 回信纸 | 收件人明确写着“下一位愿意试试的人” | 逐段增加方法、发现、条件与下一步 | 交到新人手中，玩家保留副页 |
| 桌角 | 借用老乔的空位 | 回条与小物逐渐有固定位置 | 成为玩家桌位，可以让新人借一角 |

没有记录的数值、失败、操作次数与完美表现都不能替玩家补写。旧档只有完成信息时，采用中性完成描述。

## 阿墨：喜欢整齐，也学会留白

阿墨是一只拟人渡鸦，字幕短，熟悉地址却不懂每台装置。它想和新搭档跑完完整邮路，也想让别人一眼读懂自己整理的信。

它爱捡纸夹，喜欢把文字多的信折齐；遇到长说明，会把末行折到背面。这个习惯在前半段确实帮助信袋整洁，也会在后半段遮住重要条件。问题由整个传抄过程共同造成，不能把旧稿缺漏全归罪给阿墨。

### 动作弧线

| 段落 | 可见动作 | 关系变化 |
|---|---|---|
| R01 | 在桌角留一只纸夹，挂起画着第四箱的回条 | 从“带新人跑一趟”变成期待共同收到回信 |
| R02 | 替阿澜夹好交班纸签，把两张旧图并排挂起 | 开始替搭档记住别人的约定 |
| R03 | 提议删掉不确定末行，随后发现自己的缩写也会让人读错 | 接受清楚需要听取读者的反馈 |
| R04 | 展开折角，核对原稿，再把条件夹到正面 | 承担自己能改的部分，也允许别人帮助 |
| R05 | 把条件展开，给下一步留空白页 | 成为玩家稳定的搭档，愿意让新人加入 |

R04 的动作来自剧情中的旧稿，不要求玩家实验失误。一次过关也能完整表现阿墨的成长。

### 阿墨的对白

| 情境 | 示例 |
|---|---|
| 看见第四箱留岸 | “总不能让它自己游过去吧。” |
| 只改一个实验条件 | “这回只动这一处。前后的记录能并排看。” |
| 玩家改身份答案 | “标签换过了。刚才那组测量还在。” |
| 请求提示 | “上一组船上还没有箱子。现在多了什么？” |
| 正式记录未达目标 | “先留着。下一次就知道和哪一组比。” |
| 收到首张回条 | “她连缺角都画上了。真是我们的箱子！” |
| R03 不确定是否寄出 | “这一句写‘还不知道’，也能寄吗？” |
| R04 修订旧页 | “这行我折过去了。原稿的另一行，也没写全。” |
| 结尾看见新人 | “你的桌子，要借他一角吗？” |

阿墨不会代算答案，不在连续失败后反复吐槽，不把玩家的修订当笑料。“还不知道”要和已经查过的部分一起寄出，不能成为任意猜测的理由。

## 老乔：守住可靠，也学会交出决定

老乔是潮汐港站长。他想重新守住“每晚有人接信、也有人回信”的约定。雾季之后，他保留各站旧稿，担心一份含糊说明给别人添麻烦，因此习惯在寄出前多等一等。

他没有掌握全部答案。印章原本只记录“已收”或“已寄”，但大家过去常把盖过章的页直接当作可继续使用的最新版。R03 的两份旧稿使他重新检查这个习惯。

- **日常动作**：杯子压住当天登记；每次收工给桌面留出一角；会替晚到的人把收信格留空。
- **和阿澜的关系**：知道阿澜会等最后一班，也知道对方想回去吃饭。两人曾靠口头约定交班，现在需要写清接应。
- **和小禾的关系**：保存她早期的图，欣赏整洁，却没有真正作为陌生读者试着使用。
- **中段选择**：R03 不再无限等一份“什么都确定”的说明，允许寄出有依据、注明未核对项的修订稿。
- **结尾动作**：将玩家的临时纸条换成正式收信格，把一次新的寄信决定交给玩家。

一句常用话：“这一页，下一站拿到以后能做什么？”

结尾不让老乔突然变成随意盖章的人。他依然认真核对，只是学会区分可靠记录与永不改动的答案。

## 阿澜：既记得等信的人，也有自己的收工时间

阿澜是往返潮汐港的船工，负责实际船只与码头，不负责替玩家完成推导。他珍惜熟悉路线的经验，最初会用旧航向猜新载重与新水流。

他希望夜班准时收工，也不想让刚到港的人白跑。这个分歧通过交班解决，不以无限等待证明善良。

- **日常动作**：晒绳、修凳、在木桩上系好临时纸签；热饭的念叨只点到为止。
- **和阿墨的关系**：把易丢的纸签交给它夹住，阿墨偶尔还他一个捡来的纸夹。
- **R01 动作**：空载成功后拦住加箱，提醒载重变了。三项齐备才带货离港。
- **R02 动作**：把两种航向目标分开，约好下一站接班的人；夜班开始有可持续的轮换。
- **R03 分歧**：提醒老乔对岸在等，仍愿意给必要核对留出空间。
- **R05 动作**：主动问这次载重与条件，然后按时交班，真的回去吃饭。

一句常用话：“这回和上一趟，哪一处不一样？”

实验只提供给定模型的记录。真实航行由阿澜与码头人员负责，不把二维模型演示当适航保证。

## 小禾：从想被读懂，到愿意听读者说

小禾是化学岛标本港观测窗口的观测员，是第一批货物的收件人。她需要器材，也希望自己的记录第一次被其他岛认真使用。

她擅长整理本地资料，初期觉得熟悉的标记不用逐项解释。收信时要求别人写清楚，寄信时却也漏掉自己的读图习惯。R03 让她和玩家一起成为需要改稿的人。

- **日常动作**：晾受潮信封，把第一张收条副本压在窗边；茶水放在样品区外。
- **R01 动作**：确认四箱到齐，画出第四箱的缺角；主动问夜间能否回寄日终记录。
- **R02 动作**：与轮班同伴整理夜间收寄格，寄来真实使用后的补充。
- **R03 动作**：写下“我照图做了，但这里不同”；随后附上自己的修订：“我这边也少写了一行。”
- **R04 动作**：作为共同作者补齐图册的使用说明，不把修订全推给玩家。
- **R05 动作**：用当初收到的器材记录新结果，将空出的第四箱改作回寄箱，带回新问题。

一句常用话：“我这边看到的是这样。你那边呢？”

小禾的记录有明确来源。只有真实游戏记录支持的数值才显示成玩家成果；剧情稿件与给定新资料单独标识。

## 常驻人物彼此的关系

| 关系 | 开始时已经存在的联系 | 中段分歧 | 后来的共同做法 |
|---|---|---|---|
| 老乔—阿澜 | 一个收最后一封，一个等最后一班 | 继续核对与及时出船怎样兼顾 | 写清交班和待核对项，有限等待、可靠接应 |
| 老乔—小禾 | 收藏整洁的早期图稿 | 图看上去完整，陌生人却不会用 | 保留原稿、读者反馈与修订说明 |
| 阿墨—阿澜 | 代夹纸签，熟悉收工念叨 | 纸签短了好拿，条件却可能被省去 | 把重要条件夹前面 |
| 阿墨—小禾 | 喜欢她画的箱子与小标记 | 两人的缩写各自清楚，互相会读错 | 用收到的回条检查是否真正读懂 |
| 玩家—四位伙伴 | 新人借桌角、接第一趟货 | 从执行委托到决定怎样表达未知 | 成为有固定位置、能发起新问题的合作者 |

人物可以在玩家进场时正在做自己的事。不要求每次相遇都宣布成长，也不把一场争论写成关系清零。

## 三种探索偏好

沿用 assistant、maker、skeptic 编号。选择代表本次做事的偏好，不是固定人格或科学结论的分支。

| 身份 | 偏好与动作 | 一句开场 |
|---|---|---|
| 助手 assistant | 先观察和记录，整理单位与对照页 | “先留一组，后面知道哪里变了。” |
| 工匠 maker | 先搭建和调试，再比较设置 | “换个位置，再看一次。” |
| 求真者 skeptic | 先问条件和可能的反例 | “换一个样品，这句还算数吗？” |

三种身份都能观察、推导、动手、请求提示与修改判断。现有资源结算另由关卡规则负责；人物偏好不代替证据。

## 历史伙伴也有共同记忆

每位伙伴保留一两个动作与提问习惯，避免统一使用“孤勇天才”等性格标签。

| 人物 | 本作中的动作 | 对错误的回应 |
|---|---|---|
| 阿基米德 | 先把手边材料放进水里 | “重量没变。水线哪里不同？” |
| 伽利略 | 敲一段节拍，再听小球 | “最后两声靠得更近，再比一遍。” |
| 牛顿 | 先写假设，再画轨迹 | “我们这张图没有空气，这一行留下。” |
| 焦耳 | 每次读数都核对起点和单位 | “很小也记，先排除读法的差别。” |
| 欧拉 | 排好输入与输出卡 | “同一个输入，这条规则得说清楚。” |
| 高斯 | 保留不整齐的观测点 | “这一封还没用于拟合，先别拆。” |
| 波义耳 | 盖住名称卡再比性质 | “先读测量，标签等一会儿。” |
| 拉瓦锡 | 先圈称量边界，再查账 | “气体出去了，账本的圈改过吗？” |

这些是创作表演方向。历史卡保留合作者与研究背景，不把群岛习惯解释成真实人物完整人格。

法拉第在 P06、C09 是同一人。第二次见面根据顺序承接：“上次我们看指针怎样动，这次把物质变化也记进账里。”反向顺序使用对应版本。P07 主伙伴是麦克斯韦，赫兹以后来实验记录出现。

## 对白、开场与重访

每次进入关卡播放可跳过的短开头。通常两轮内交出操作权，目标留在舞台旁。重访也有开场，但承接已送达、已修订与已见面的事实。

主线前提前访问：人物处理同一份本地资料，不提前发生段落交付。段落到来时直接引用已有记录。

主线后重访：可以看到用过的图、已挂起的回条或新核对请求；不重演第四箱永远装不上船。

人物反馈来自当前参数与记录。提示先推进一步，详细历史、模型与推导由玩家自行展开。正式失误指向条件、证据或推理，幽默不拿失败和身体特征开玩笑。

## 三类能留下回应的选择

1. **回信引用**：从已完成的真实记录中选一项，结尾有对应小图与一句回应。玩家先做了哪科都能成立。
2. **修订公开**：愿意时附上已有改正过程；没有失败也能附条件比较或未试问题，不编造挫折。
3. **桌位物件**：从实际收到的信物中选一件，重访时有人偶尔提起来。未取得的物件不出现在选项里。

选择不额外阻塞交付。不操作时使用明确的默认项，不强制写作文、不增加进入实验前的确认层级。

## 人物验收

- 四位常驻人物各有愿望、分歧、一次主动选择与一个结尾动作。
- 玩家能记住至少一件人物在任务之外正在做的小事。
- 阿墨始终是玩家搭档，新人加入时不自动离开。
- 人物记得共同经历，但不声称玩家做过不存在的测量或故意失败。
- 跳过演出、自由顺序、旧档与重做都不让人物失忆。
- 情感变化通过寄出、使用、回应和修订体现，避免每段结尾长篇说教。
