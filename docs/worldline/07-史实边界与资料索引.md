# 史实边界与资料索引

版本：第三版，2026 年 10 月 19 日。本轮补齐叙事边界，保留第二版三十关科学条件与资料入口；新增人物和邮路事件均为创作。

群岛允许不同年代的人物共同参与虚构邮路。历史资料说明这些人物真正研究过什么，关卡说明玩家此刻使用什么模型；两者分开呈现。资料来源支持对应的历史或科学内容，不给创作对白、心理描写和邮局事件背书。

## 三层内容怎样标注

| 内容层 | 可以写什么 | 呈现方式 |
|---|---|---|
| 历史资料 | 有来源支持的研究、著作、合作与背景 | 单独资料卡，附来源和必要年代 |
| 教学改编 | 简化模型、现代解释、改变后的器材与虚构数据 | 在读数或图旁说明对应条件，详细范围放手记 |
| 群岛故事 | 信使、阿墨、邮局、委托、跨年代对话 | 作为本作创作呈现，不加伪造的历史引号与文献年份 |

对白可以有鲜明的语气，但不宣称还原真实人物的私下口吻。描写“本作中的牛顿会先写假设”即可，不用未经支持的童年经历解释其一生性格。病痛、危险与孤独不作为天才身份的必需装饰。

## 第三版故事的资料边界

老乔、阿澜、小禾、阿墨、夜邮停航、四箱货物与站章均为群岛故事，不伪装成真实历史背景。跨年代合作采用统一的虚构群岛空间；历史卡仍按真实年代说明贡献与承接。

玩家取得的实验记录、章节给定旧稿、NPC 的使用反馈与后来加入的教学资料，在手记里分别标明来源。R03 的旧稿差异不追认玩家此前正确记录为错误；R05 的新资料不捏造玩家未做过的测量。

角色成长不要求故意失败。阿墨折去的末行来自剧情旧稿；玩家自己的有效条件不能被剧情偷偷移走后再用于判错。无失败玩家可通过条件比较、用途说明与未试问题完成全部人物线。

三站复航由居民负责实际设施、值班与航行。教学模型的成果能帮助他们核对说明，但 P01 不提供完整适航评估，P06、C10 不承担整港供电，M05 不提供桥梁承重证明，M10 不生成真实夜航预报，P10 的电子不直接驱动机械柜门。

“已收”“已寄”章只表示收寄；改稿保留日期、来源和变化。印章、人物声望与剧情奖励都不替代证据或数学论证。

## 优先遵守的历史边界

### 伽利略与铃铛斜面

伽利略博物馆保存的铃铛斜面是用于演示相关运动规律的后世装置，馆方也明确说明没有存世文献证明伽利略进行过这一个具体实验。P02 可以借其声学反馈组织三钟任务，历史资料不能写成伽利略原样布置了本关。

依据：[伽利略博物馆斜面藏品](https://catalogue.museogalileo.it/object/InclinedPlane.html)。

### 法拉第的机构与跨学科工作

物理岛的感应和化学岛的电解研究都可以采用法拉第原型。人物在两岛是同一人，不凭学科分区拆成两个陌生角色。涉及其研究场所时使用 Royal Institution 对应名称，不能和 Royal Society 混为一处机构。

依据：[皇家研究所人物资料](https://www.rigb.org/explore-science/explore/person/michael-faraday-1791-1867)、[1831 年感应环藏品](https://www.rigb.org/explore-science/explore/collection/michael-faradays-ring-coil-apparatus)。

### 周期分类与电子解释

门捷列夫的周期分类以当时的元素资料为背景，早于用现代原子结构解释周期规律。C03 的电子层、价电子属于后来的教学说明，采用单独附页或明确的转场。历史人物整理性质卡片和现代粒子模型可以同关出现，不能写成同一项当年的发现。

依据：[英国皇家化学会周期表发展史](https://periodic-table.rsc.org/about)。

### 立体化学与现代水分子模型

范特霍夫的四面体碳思想可以作为 C06 的历史背景。现代甲烷、水的模型、键角与电子域说明各自标注，不把所有后续解释归为他的原实验。涉及立体化学贡献时保留勒贝尔等人的工作，不塑造单人包办全部成果的桥段。

依据：[诺贝尔奖现代化学发展史](https://www.nobelprize.org/prizes/themes/the-nobel-prize-in-chemistry-the-development-of-modern-chemistry/)、[OpenStax 分子结构与极性](https://openstax.org/books/chemistry-2e/pages/7-6-molecular-structure-and-polarity)。

### 麦克斯韦与赫兹

P07 主人物与现有编号保持为麦克斯韦，理论工作与赫兹后来的实验分开说明。现代调谐、报码与收发图是教学类比，不能把整套故事装置署名为麦克斯韦亲自发明和演示。

历史工作可从[麦克斯韦《电磁学通论》中的光的电磁理论](https://www.cambridge.org/core/books/abs/treatise-on-electricity-and-magnetism/electromagnetic-theory-of-light/FD07B196379A1F86D55969E409020EC9)进入，器材与演出另行标注。

## 三十关的科学边界

这些条件需要在具体关卡里就能读到，不能只藏在本文件中。普通玩家先看到一句与当前判断相关的说明，愿意继续读的人再展开完整模型。

| ID | 不能被剧情省略的条件 |
|---|---|
| P01 | 船型影响进水前承载余量；漂浮时仍满足重量与浮力平衡，模型未验证侧翻和真实适航性 |
| P02 | 理想滚动、给定坡度与释放条件；演示铃声不替代对真实时间与距离的定义 |
| P03 | 无空气等假设下的思想实验；轨迹不是可直接执行的真实发射计划 |
| P04 | 温升很小、展示可放大；能量账目需考虑热损失，不能描写几次搅拌烧开水 |
| P05 | 相干单色光与指定双缝条件；不能由一种干涉图样解释全部光现象 |
| P06 | 感应与磁通变化相关，机械运动有能量输入；静止磁铁不是持续无源电源 |
| P07 | 理论、后来的实验和现代编码演示分层；动画速度不等于实际传播速度 |
| P08 | 虚拟读数须在同等条件比较；异常是继续调查的依据，不能单凭发光或一次测量宣布发现新元素 |
| P09 | 给定振子能量交换规则的量子化类比；不把任意宏观能量都离散成相同硬币 |
| P10 | 给定弱光单光子模型与材料逸出功；强度和频率的作用不同，不使用“光子排开电子” |
| M01 | 有限分数逼近不是无理性的证明；提出数学结论时提供相应推导 |
| M02 | 只做一步应显示正确中间式；完整求解、代回检查与实物可操作范围不能互相矛盾 |
| M03 | 坐标有原点、方向、单位和次序；一条示意线不等于已检查障碍的真实航线 |
| M04 | 定义范围内每个输入有一个确定输出；不同输入可有相同输出，对应关系不等于因果关系 |
| M05 | 检查几何端点与区间净空；不计算真实承重，不由一张轮廓图保证桥梁安全 |
| M06 | 刚体变换与相似缩放分别讨论；缩放改变长度与面积，操作顺序可能影响结果 |
| M07 | 先检查非退化三角形与欧氏平面前提；试例不能替代一般推理 |
| M08 | 同一参照系下合成速度；固定河宽与船速的最短时间目标不等同于直达正对岸 |
| M09 | h(t)=100−8t+0.2t² 的 t=20 是极小值；驻点不必为极值，更不自动是拐点 |
| M10 | 虚构观测和二次模型；独立检验不能提前参与拟合，不称作谷神星真实轨道复原 |
| C01 | 指定纯样品、测量条件和参考范围；改身份标签不是改变实验变量 |
| C02 | 现代组成与取整原子量；相同元素可以形成不同组成，不涉及核变化 |
| C03 | 历史分类与现代电子层解释分开；简化主族规则不覆盖所有元素 |
| C04 | 局域电子对模型；总孤对的计数范围明确，O₂ 顺磁性等需要更进一步模型 |
| C05 | 化学式下标与前方份数不同；分子式不确定全部结构，全部物质也并非都由独立分子组成 |
| C06 | 原子构型、电子域与投影区别；转视角不改变真实键角，非理想角不继续称作正四面体 |
| C07 | 单键偶极与合偶极分层；箭头采用明示图例，不把它当电流或机械力 |
| C08 | 称量系统边界明确；放气示例与水生成配平为两个任务，只谈普通化学反应 |
| C09 | 外加电源电解与电池反应区别；电量计量写明价态和理想效率，盐桥不输送电子 |
| C10 | 外电路电子与内部离子通路区别；化学能来源与材料消耗不可隐去，单节模型不驱动整座灯塔 |

## 其他资料入口

资料编辑需要核对具体主张与原文，不因为来源标题里出现人物姓名，就用它支持整段生平或创作心理。以下入口用于查相关背景，引用时只保留它实际支持的内容。

- 物理的测量、光量子和放射性背景：[诺贝尔奖物理研究脉络](https://www.nobelprize.org/prizes/themes/the-nobel-prize-in-physics-1901-2000/)。
- 毕达哥拉斯传统与人物记载问题：[斯坦福哲学百科](https://plato.stanford.edu/entries/pythagoreanism/)。
- 古典几何命题与推理背景：[欧几里得《几何原本》在线版本](https://mathcs.clarku.edu/~djoyce/java/elements/elements.html)。
- 波义耳、道尔顿、阿伏伽德罗与拉瓦锡背景：[Science History Institute 科学人物资料](https://www.sciencehistory.org/education/scientific-biographies/)。
- 电子对模型的原始论文：[Lewis The Atom and the Molecule](https://pubs.acs.org/doi/10.1021/ja02261a002)。
- 现代原电池说明：[OpenStax 原电池](https://openstax.org/books/chemistry-2e/pages/17-2-galvanic-cells)。

现有学科数据中的 source 或 sources 可作为进一步检索入口。遇到“第一”“唯一”“独自完成”“一夜发现”“所有理论全部失效”等强断言，先确认主张需要的证据；能用具体贡献表达时，直接写具体贡献。

## 写入游戏前的编辑检查

历史卡核对人物、研究内容、年代与合作者；创作卡核对玩家知道的条件；结果卡核对模型、读数和正式记录。三张卡承担不同的解释，不互相借名义。

若一句诗意比喻会改变知识含义，先把关系说清楚再保留少量比喻。例如“给数字方向”之后仍应指出箭头代表哪一个量；“能量包”之后仍应说明它属于哪一个模型。保留趣味的同时，让玩家带走可复用的理解。
