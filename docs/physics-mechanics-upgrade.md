# 物理岛机制升级：让证据改变判断

保留十位人物、各自的彩色像素场景、三幕结构、三种身份和四种结局。升级取证与论证过程，不增加强制倒计时或新的货币。

## 1. 调查可以接着做实验

调查不再只能代替一幕实验。调查结算后可以带着线索进入同幕实验；实验台也可花一格时间请人物排查。每幕只结算一次调查，完整线索只在调查后显示，初始方法提示不直接给出答案。

同一幕的调查与实验取最强证据，最多强度2，不靠重复行动叠分。成功实验可以替换较弱的调查记录；过程记录完整保留。

## 2. 预判、观察、对照

每个实验有符合该物理情境的可选预判。预判只记录思路，不决定物理判定，也不额外奖惩资源。运行后将预判与实际现象并列；没有完成本幕目标的实验也进入记录。

实验结束后可以建立同幕对照。以最近一次实验为参照，只改一个设置；每幕首次公平对照只花时间1，不再消耗器材。零变化与多变量变化不能作为该对照提交，可切回普通复验。后续复验按正常成本结算，避免无限低成本试错。

对照结果同时显示改动、前后读数、哪些条件保持不变。参数组合选择仍由玩家完成，场景随装置更新。

## 3. 用记录组织结论

第三幕取消暗示答案的三个大按钮。玩家选择一个解释、从本次实际行动中选1—3条记录，并选择结论适用范围，再提交论证；也可以保留结论。

论证只使用选中的有效记录计分，同一幕不重复叠加。成立仍需跨两幕的证据、至少一次成功实验、证据强度至少3和正的信任。错误解释或不受支持的论证会留下具体反馈；把结论推到所有条件会得到过度推断结局。保留结论不要求凑足证据。

结局展示“先想后试”“公平比较”“证据成链”三个本次研究印记，鼓励观察和修正，不以预判正确率排名。

论证未成立或过度推断后，可以使用已有记录修订解释和适用范围，无需重新完成实验，也不再扣资源；此前的结局收藏和通关状态保留。缺少新数据时仍可重玩探索。

## 兼容与验收

继续使用 physicsScenarios 的版本4存档。旧事件缺少研究附注时按原规则重放，原通关状态、地图复色和结局收藏保留。新事件附上经校验的预判、跟进方式与论证选择；资源、对照资格、证据和反馈均由事件重新计算。

检查十关二十个实验的现象预判、调查跟进、公平对照的成本与限制、论证对结局的真实影响、旧事件重放、刷新续玩、键盘和手机操作。
