# 物理岛关卡设计

> 本篇为旧版设计存档。当前故事版见 [物理岛·十封未寄出的信](物理岛·十封未寄出的信.md)。

物理岛的主题为“万象之境”。以一座有山脉、河流、瀑布和海湾的连续岛屿，串起观测、力学、能量与电学。大地图承担学科导航，岛内关卡承担地标探索；两者使用不同画面与交互对象。

十个地标现已全部实现独立实验关卡。每关的场景、两项任务、理解验证与模型边界见 [物理岛十关远征设计](物理岛十关远征设计.md)。本篇记录岛屿地形、视角与迷雾设计。

## 岛屿分区

| 分区 | 地形与装置 | 对应知识 |
| --- | --- | --- |
| 启程海湾 | 西南码头、测量杆、观测三脚架、计时跑道 | 位置与运动、速度与加速度 |
| 力学高地 | 西部庭院的牛顿摆、杠杆、滑轮，中央抛体试验场与向量桥 | 向量与分解、力与运动变化、抛体运动 |
| 能量河谷 | 河流、落差、水车、起重装置、水力发电站 | 功与能量、能量转换 |
| 场与电之丘 | 东部高台的摆锤与场线雕塑、电势双塔、闭合电路花园 | 场的初步概念、电势差、电流与电路 |

河流把高处的落差、水车转动和发电站联系起来。科学装置参与建筑轮廓与场景叙事，而不是作为悬浮图标贴在普通村庄上。装置属于示意性场景，准确的规律、模型边界与验证由知识卡和实验呈现。

## 两种视角

大地图显示三座学科岛的入口与探索迷雾，选择入口可查看该岛简介，再进入关卡。物理岛使用独立底图与十个地标；数学、化学保留已有知识地图和实验，本轮未重绘其独立地形。

左上“大地图／当前关卡”切换视角，顶部学科导航可直接前往对应学科。返回时保留本次会话里的缩放与位置，不要求等待角色走路。

## 迷雾规则

- 默认开启，提供关闭与恢复按钮。
- 世界地图初始显示物理远征入口与中央港湾；进入或探索其他学科后展开相应区域。
- 物理岛初始展开西南登陆海湾。远处只显示问号与“未探索地标”，可以直接点击调查。
- 访问地标后揭开附近地形，并显示地点名称与正式知识概念；已有访问记录同样参与揭雾。
- 揭雾由独立 SVG 遮罩绘制，柔化边缘，不把雾画进底图。
- 访问记录保存在当前浏览器，刷新后仍然有效；关闭迷雾只是查看全图，不改变访问与验证记录。
- “探索地标”“完成实验”“通过理解验证”分别记录，揭雾不会自动标记理解。

## 核心探索循环

进入物理岛 → 在观测港口登陆 → 选取地标调查 → 阅读概念或进入实验 → 揭开邻近区域 → 沿地形和知识联系继续探索。

“查看完整岛屿设计”会关闭迷雾、恢复整岛比例并收起侧栏，便于先看完整地形。再次打开迷雾后，已发现的区域保持清晰。
