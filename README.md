# 知识群岛

> 把问题寄出去，等一封回信。

![知识群岛 · 三岛世界地图](docs/assets/screens/02-world.png)

## 一个真实的问题

教材按章节组织知识。学习者能背下公式，却常常答不出三件事：

- 这个概念**为什么需要**？
- 它和**已经学过的什么**有关？
- 它能**解释什么现象**？

《知识群岛》就是为这三个问题做的。它不按章节排列知识，而是把物理、数学、化学还原成三十个**尚未解决的研究现场**——每一处都停在一个具体的人、一个卡住的实验、一封没寄出的信上。

你的身份不是考生，是刚来潮汐港报到的新信使。

---

## 这是什么

**一张可以航行的学科地图，和一条要你自己跑通的邮路。**

三座岛各自荒废了很久：物理岛的船装不下最后一箱货，化学岛的样品签受潮看不清，数学岛上「右上那间」没人找得到。你要做的不是背答案，而是把三件事查清楚，写成对岸能用的记录，寄出去——然后等一封回信，上面可能写着：

> 「我照图做了，但这里不同。」

这句话是整个产品的核心。**能被别人使用、能被追问、能再回来**，才算真的弄明白了。

---

## 核心体验

```
选择问题 → 作出预测 → 操作与观察 → 组织论证 → 寄出成果 → 收到回条
```

![第一关：潮汐港的码头现场](docs/assets/screens/03-workbench.png)

每一关按三幕推进，而不是一次答题：

| 幕 | 你要做的事 | 代价 |
|---|---|---|
| 建立参照 | 在同一条件下先做一次，留下基线 | 时间、器材 |
| 面对新条件 | 只改一个变量，做公平对照 | 时间、器材、证据强度 |
| 提交结论 | 选解释、选证据、划适用范围 | 可靠度 |

- **三种身份**改变玩法：探索者多两格时间；工匠器材更多，且首次实验免器材；求真者初始信任更高、首次调查线索更强。
- **四种资源**互相牵制：时间、器材、可靠度、证据强度。
- **论证要成立**，必须覆盖两幕、支持强度 ≥ 3、至少一次成功的完整实验，且信任为正。差一条，结论就降级成「保留结论」或「过度推断」。
- **失败不是终点**：实验读数会留下来，可以免费调试、免费修订，只是这一次的时间跟器材真的花掉了。

三座岛、三十个现场、五段邮路主线、十五项补充委托，加上四位会记得你的常驻伙伴（老乔、阿澜、阿墨、小禾）。

## 技术方案

**零框架、零构建、零运行时依赖。**

纯原生 HTML / CSS / JavaScript，地图与关卡美术全部用 Canvas 和 SVG 由代码绘制，不依赖位图切图。克隆下来直接打开就能跑，没有 `npm install` 这一步（测试除外）。

这个取舍是产品判断，不是技术炫技：这类内容产品最怕「改一个交互要动三层工具链」。原生加按领域拆文件，让每次改动都能收在单个文件里。

| | |
|---|---|
| 规模 | 98 个 JS（1.34 MB）、30 个 CSS（424 KB）、2 个 HTML 入口 |
| 美术 | 世界地图与三岛底图为像素插画；关卡场景、人物、装置全部代码绘制 |
| 存档 | `localStorage`，单一命名空间 `knowledge-islands-v2`，含旧档迁移与损坏保护 |
| 适配 | 键盘操作、减少动态效果、320–2560px 布局、触屏手势 |

## 给谁用

- **初三到高中阶段的学习者**：想知道公式从哪来、章节之间怎么连。
- **想把基础科学重新理一遍的成年人**：不需要从头刷题，只需要一条能走通的路径。
- **教师与家长**：想用一个现象引出三种学科解释，做课堂演示。

典型使用场景是课后十到十五分钟的自主探索，或课堂上的一次单点演示。

不是「效果很好」，是可以自己跑一遍的东西：

- **30 个现场全部可玩**，15 项主线加 15 项补充委托，5 段交付构成完整主线与结局。

## 这不是什么

写清楚边界，比堆功能更可信：

- **不是完整课程，不做应试训练。** 它承担的是「建立联系」，不是覆盖考纲。
- **分子模型是有限模板与二维投影**，不是任意化学结构的真实模拟。
- **历史人物对白是创作。** 真实年代、合作者与来源，在独立的史料卡里另给出处。
- **不接大模型。** 事件与判定由本地规则结算，没有 AI 问答，也不需要联网。
- **没有账号、没有云同步。** 进度只存在当前浏览器；换设备或清缓存会归零。
- **入口偏长。** 从首页到第一次动手要经过六幕序章与开场动画，这是已知问题，正在压缩。

## 开始使用

```bash
npm start          # 本地预览 http://127.0.0.1:4173
```

也可以直接用浏览器打开 `index.html`（本地文件模式下存档行为取决于浏览器）。

首次跑浏览器回归前需要装依赖：

```bash
npm ci                         # 安装 Playwright CLI
npm test                       # 447 项单元测试
npm run test:browser           # 高优先回归
npm run test:browser:harbor    # 首页序章与飞行入场
npm run test:browser:map-activation
npm run verify                 # 完整验收，可加 -- --resume 续跑
```
