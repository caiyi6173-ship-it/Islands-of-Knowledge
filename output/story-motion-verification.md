# 首页六幕动态效果验证

2026-10-28

在现有蓝色航海、像素人物和六幕故事上加入原生 CSS 与 SVG 动效，无新增运行时依赖。

| 场景 | 动态细节 |
|---|---|
| 海的那边 | 海雾、远鸟、海面反光，背景与前景随滚动错层移动 |
| 三座岛 | 邮路逐渐绘出，虚线流动，港口信号与航图薄雾 |
| 我的桌角 | 窗外云影、纸页轻动、信袋与铅笔的微小动作 |
| 搭档阿墨 | 渡鸦眨眼、身体轻动、纸夹摆动与信封起伏 |
| 第一份委托 | 三箱小船随波起伏，第四箱和委托单入场，水纹流动 |
| 我想试试 | 角色呼吸、阿墨在栏杆上准备出发，衔接原有飞行 |

六幕文字按层次入场，插画采用滚动视差，顶部显示阅读进度。桌面整屏停靠；手机和矮屏自由滑动，避免短滑被吸回。环境循环在离屏、切出标签页、准备飞行和抵达后暂停；系统减少动态效果关闭动效与视差。SVG 固定坐标保留在外层，局部动画在内层围绕正确支点运动。

验证：447 项单元测试，18 个浏览器场景通过，页面错误 0。首页组实际检测六幕循环的时间推进、离屏暂停、支点、手机原生触摸、320–768px 与横屏、减少动态、逆向阅读、取消和重播、缺图、保护存档、原版关卡开场和真实地图交接。地图组实际双击全部三十关，验证岛屿、邮局、任务卡和触屏操作。
